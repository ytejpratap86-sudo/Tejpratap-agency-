# Tej Web Hub

Static multi-page website (generated) + admin panel + client portal, backed by Supabase.

## Layout
- `public/` - the deployable site (Netlify publish directory). Generated by `tools/build.py`.
- `tools/build.py`, `tools/style.css`, `tools/app.js` - source for the public pages. Edit these, then run `python3 tools/build.py`.
- `static/admin.html`, `static/portal.html` - admin panel and client portal (copied into `public/` by the build).
- `supabase/` - first two migrations, the `send-emails` Edge Function and the cron setup. Later migrations (projects, client portal,
  notifications, email queue, public website CMS) were applied directly to the database: run `supabase db pull` to export them.

## Deploy to Netlify
Connect this repo (publish directory `public`, no build command) or drag the `public/` folder into Netlify.

## Configuration (stored in the database, not in code)
Insert rows into `site_settings` (Supabase Table Editor) with `is_public = true`. Nothing is shown until you add them:
`whatsapp_number` (digits with country code), `whatsapp_message`, `whatsapp_cta`, `contact_email`, `social_instagram`, `social_linkedin`, `social_facebook`.
Portfolio entries go in `portfolio_projects` (set `is_published = true`); real testimonials in `testimonials`.

## Security notes
The Supabase URL and publishable key in `app.js` are public by design; Row Level Security protects data. Never add a service-role key to any file here.
